# Installing Z-Stream on Windows

Z-Stream is available as a Windows application. Download the latest version from the official apps page:

[https://zstream.mov/apps](https://zstream.mov/apps)

## **Installation Steps**

1. Download the latest **Z-Stream Windows installer** from the official apps page.
2. Open the downloaded installer file.
3. If Windows shows a security warning:
   - Click **More info**.
   - Click **Run anyway** to continue.
4. Follow the setup instructions.
5. Launch **Z-Stream** from your desktop or Start Menu.

---

<Warning>
  ### False Trojan Detection Notice

  Some users may see a false malware warning when installing or updating the Z-Stream Windows App. This is caused by the PowerShell-based updater being incorrectly flagged by some antivirus software.

  Microsoft has reviewed the file and confirmed it shows **“No malware detected”**, and updated [Windows Defender definitions](https://www.microsoft.com/en-us/security/portal/definitions/adl.aspx) no longer flag the issue.

  If you still receive a warning, you can temporarily disable your antivirus, install Z-Stream, and add the app folder as an exclusion in Windows Defender. Make sure your security definitions are updated before reinstalling.
</Warning>
