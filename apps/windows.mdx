# Installing Z-Stream on Windows

Z-Stream is available as a Windows application. Download the latest version from the official apps page:

[https://zstream.mov/apps](https://zstream.mov/apps)

## **Installation Steps**

1. Download the latest **Z-Stream Windows installer** from the official apps page.
2. Open the downloaded installer file.
3. If Windows shows a security warning:
   - Click **More info**.
   - Click **Run anyway** to continue.
4. Follow the setup instructions.
5. Launch **Z-Stream** from your desktop or Start Menu.

---

## False Trojan Detection Notice

Some users may see a false malware detection warning when installing or updating Z-Stream on Windows.

This is caused by the PowerShell-based automatic updater being incorrectly detected by some security software. The issue has been submitted to Microsoft for review.

Microsoft has re-reviewed the file and confirmed that it shows as **"No malware detected"** on their end. The latest Microsoft Defender definitions for Windows 11 no longer flag this issue.

To update your Microsoft Defender definitions, visit:

[https://www.microsoft.com/en-us/security/portal/definitions/adl.aspx](https://www.microsoft.com/en-us/security/portal/definitions/adl.aspx)

Other major antivirus providers have also confirmed that the Z-Stream Windows App is safe. You can verify the file through VirusTotal if needed.

If your antivirus still shows a warning, make sure your security definitions are updated before trying the installation again.
