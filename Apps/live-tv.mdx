# Installing ZStream on Android

<Accordion title="Method 1: App APK">
  1. Download the latest **ZStream APK** from the [Downloads page](https://zstream.mov/apps).
  2. If prompted, allow your browser or file manager to install unknown apps.
  3. Open the downloaded APK and tap **Install**.
  4. Once installed, open ZStream and enjoy.
</Accordion>

## **Updating**

Z-Stream automatically checks for updates and installs the latest version when available.<br /><br />Android installs are provided as an APK. You may need to enable **Install from Unknown Sources** in your device settings before installing. Always download the APK from the official [**zstream.mov/apps**](https://zstream.mov/apps) page.

# Installing ZStream on Android TV

<Accordion title="Method 1: Install with the Z-Stream Android App (Recommended)">
  - Install the ZStream Android app on your phone.
  - Make sure your phone and Android TV are connected to the same Wi-Fi network.
  - Open the ADB Installer in the ZStream app.
  - Select your Android TV and install the latest ZStream TV APK.
</Accordion>

<Accordion title="Method 2: Install with an ADB Installer">
  If you don't have the Z-Stream Android app, you can use an ADB installer such as ADB TV.

  Download ADB TV:<br />[https://play.google.com/store/apps/details?id=com.cybercat.adbappcontrol.tv](https://play.google.com/store/apps/details?id=com.cybercat.adbappcontrol.tv)

  Connect to your Android TV, select the latest ZStream TV APK, and install it.
</Accordion>

<Accordion title="Method 3: Install Using a PC (ADB)">
  ou can install Z-Stream on Android TV using ADB from a computer.

  ## Requirements

  - A Windows, macOS, or Linux computer
  - Android TV connected to the same network
  - ADB installed on your computer

  Download ADB:[https://developer.android.com/tools/releases/platform-tools](https://developer.android.com/tools/releases/platform-tools)

  ## Installation Steps

  1. Enable **Developer Options** on your Android TV.
  2. Enable **Wireless Debugging** or **ADB Debugging**.

  ### If Using Wireless Debugging

  You need to pair your TV with your computer first.

  1. Open **Wireless Debugging** on your Android TV.
  2. Select **Pair device with pairing code**.
  3. On your computer, run:

  ```bash
  adb pair TV_IP_ADDRESS:PAIRING_PORT
  ```

  4. Enter the pairing code shown on your TV.

  ### Connect to Your TV

  If you are using **ADB Debugging**, you can skip the pairing step and connect directly.

  Run:

  ```bash
  adb connect TV_IP_ADDRESS:PORT
  ```

  ## Install ZStream

  After connecting, install the ZStream TV APK:

  ```bash
  adb install ZStream-TV.apk
  ```

  Once installed, open Z-Stream from your Android TV apps.
</Accordion>
